1 🖥️ Mon environnement technique

Un serveur personnel entièrement administré par mes soins : virtualisation, conteneurs Docker, supervision et réseau privé sécurisé. Un vrai terrain de jeu pour comprendre les systèmes de bout en bout.

⚙️ Serveur & OS

  • Processeur AMD Ryzen 5 5600X — 4 vCores
  • Mémoire 7,1 Go RAM
  • Stockage 20 Go disque
  • Système Ubuntu 26.04 LTS (VM)
  • Conteneurisation Docker + Compose
  • Configuration /opt/server/docker-compose.yml

🧱 Stack logicielle (Docker)

  • Reverse proxy Nginx
  • Base de données PostgreSQL 17
  • Administration BDD pgAdmin
  • Gestion Docker Portainer
  • Supervision Netdata (métriques live)
  • Cache & app Redis · Node.js (Express)

🌐 Réseau

  • VPN mesh Tailscale
  • Périmètre Appareils de la famille
  • Accès services Via Nginx (reverse proxy)
  • Philosophie Auto-hébergé, zéro cloud payant

🔒 Sécurité

  • Chiffrement HTTPS (déploiement en cours)
  • Pare-feu Firewall (règles restrictives)
  • Isolation Services conteneurisés
  • Accès distant VPN Tailscale uniquement

🏠 Services hébergés en production

ServiceRôleTechnologieAccès
🌐 Portail personnel Application web (auth, dashboard) Node.js · Express · PostgreSQL · Redis Nginx reverse proxy
📁 FileBrowser Gestionnaire de fichiers web FileBrowser (Docker) Nginx (/files/)
🗄️ pgAdmin Administration base de données pgAdmin 4 (Docker) Nginx (/pgadmin/)

4 🎯 Pourquoi cette approche est pertinente pour le poste

Un testeur expérimenté qui maîtrise l'IA ne remplace pas son expertise : il l'amplifie. Voici comment mon mode de travail rejoint directement les exigences du métier de test.

🧪 L'IA au service du test

Génération de cas de tests à partir de specs (le cas doc : 874 tests), création rapide de scripts Playwright/Jest/Cypress, exploration des cas limites — je garde la main sur la validation et le jugement métier.

📈 Efficacité mesurable

Les chiffres parlent : 22/22 tests verts, CI/CD en place, documentation livrée. L'IA accélère la production, la rigueur de l'ingénieur de test garantit la qualité.

🤝 Esprit d'équipe… avec des agents

Délégation, spécialisation, vérification croisée : mon workflow IA reproduit les bonnes pratiques d'une équipe projet (dev, QA, DevOps, doc). Je sais piloter des acteurs spécialisés vers un livrable unique.

🔧 Culture technique complète

Serveur, Docker, BDD, réseau, CI/CD : je comprends l'environnement que l'on teste. Cette vision système permet de diagnostiquer vite et de dialoguer efficacement avec les développeurs.
